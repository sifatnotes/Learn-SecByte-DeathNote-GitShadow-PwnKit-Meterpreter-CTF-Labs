This repository organizes hands-on cybersecurity and CTF labs focused on **DeathNote lab setup, web-to-root concepts, GitShadow investigation, Git-based privilege escalation, PwnKit/Polkit security, shell escalation, Meterpreter, and SSH pivoting**.

The collection is designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical Linux security and privilege-escalation skills in controlled environments.

## Learning Path

A practical progression for this collection is:

1. **Set up the lab** — begin with the DeathNote environment.
2. **Understand web-to-root concepts** — learn how different security stages can connect.
3. **Investigate Git artifacts** — study GitShadow and Git-related discovery concepts.
4. **Practice shell escalation** — understand how discovered information can lead to higher privileges.
5. **Study PwnKit and Polkit** — explore local privilege-escalation concepts in an isolated environment.
6. **Explore Meterpreter** — understand its role in controlled post-exploitation training.
7. **Study SSH pivoting** — connect access and movement concepts within the lab.
8. **Combine the skills** — practice building a complete CTF workflow from initial discovery through privilege escalation.
